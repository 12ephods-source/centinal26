# Frost Account Goal Ledger

`GOALS.json` is the canonical machine-readable account-wide goal inventory.

Rules:

1. A goal is not complete because a narrative says so; its required artifact/evidence and applicable verification must exist.
2. `BLOCKED_EXTERNAL` is not success and does not block unrelated goals from advancing.
3. Host/CI evidence never substitutes for authentic Android/Termux device evidence.
4. Software completion and deployed-app completion remain separate states.
5. Recurring failure classes should reuse verified repair patterns before inventing new machinery.
6. Duplicate controllers/watchers should be consolidated into a single owner plus narrow specialist lanes.
7. Goal state changes must preserve prior evidence/provenance; regressions demote rather than overwrite history.
8. Productization claims require measurable value evidence; realized revenue requires transaction evidence.
9. Scientific claims retain separate software, numerical, empirical, and scientific-verdict gates.
10. The master controller should prioritize work by expected value, risk reduction, dependency unlocking, information gain, and human-labor reduction.

The account-wide autopilot should reconcile this ledger against current evidence and update it through bounded versioned changes as goals advance.
